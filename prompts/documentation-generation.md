# Codex CLI - Documentation Generation

For the given folder, produce a README that covers:
1. What the service/project is in one sentence.
2. Quick start (install, setup, test).
3. File layout with one-line descriptions.
4. Core concepts the reader must know.
5. Common operations with code snippets.
6. Production notes (concurrency, retries, quotas, cost).
7. IAM / security minimum policies.
8. Floci vs real AWS differences.
9. Links to related services / phases.

## Tone
- Direct, no fluff.
- Code blocks must be runnable.
- Tables for comparison data.
- Mermaid diagrams when architecture spans >3 components.
